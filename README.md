# HSR Chest Overlay — обновления и данные

Официальный источник данных для программы **HSR Chest Overlay**.

## Скачать программу

[**→ Скачать HSR Chest Overlay 1.6.0**](https://github.com/g9620432-design/HSR-CHESTOVERLAY/releases/latest)

## Что умеет

- Персонажи, готовые сборки, оценка реликвий в процентах
- Калькулятор урона и мета-команды
- Данные обновляются автоматически — новые персонажи HSR появляются сами, переустанавливать ничего не нужно

## Частые вопросы

**Windows пишет «Windows защитил ваш компьютер».**
Нажмите «Подробнее» → «Выполнить в любом случае». Для небольших программ без платной цифровой подписи это обычное дело.

**Купил ключ на FunPay — где его ввести?**
Откройте раздел «Активация» в программе, вставьте ключ и нажмите «Активировать». Ключ бессрочный.

**Как получить новую версию программы?**
Программа сама предложит обновление, когда выйдет новая версия — просто нажмите кнопку.
