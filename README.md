# HSR Chest Overlay — обновления и данные

Официальный источник данных для программы **HSR Chest Overlay**.

## Скачать программу

[**→ Скачать HSR Chest Overlay 2.0.0**](https://github.com/g9620432-design/HSR-CHESTOVERLAY/releases/latest)

## Что умеет

- Карта сундуков и головоломок прямо поверх игры — следует за персонажем
- Оценка реликвий в процентах, калькулятор урона, готовые сборки
- «Прыжки» — история круток и гаранта, «Прокачка» — материалы на персонажа, «Сегодня» — сбросы, энергия и промокоды
- Звук рядом с сундуком, время маршрута, обновление данных в один клик
- Данные обновляются автоматически — новые планеты и сундуки появляются сами, переустанавливать ничего не нужно

## Частые вопросы

**Windows пишет «Windows защитил ваш компьютер».**
Нажмите «Подробнее» → «Выполнить в любом случае». Для небольших программ без платной цифровой подписи это обычное дело.

**Купил ключ на FunPay — где его ввести?**
Откройте раздел «Активация» в программе, вставьте ключ и нажмите «Активировать».

**Как получить новую версию программы?**
Программа сама предложит обновление, когда выйдет новая версия — просто нажмите кнопку.
